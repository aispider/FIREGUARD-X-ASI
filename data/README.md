# FIREGUARD-X ASI — Data Directory

This directory organizes research data used by the FIREGUARD-X ASI prototype.

## Folders

- `raw/` — Original source files, preserved without modification.
- `processed/` — Derived or transformed files, with processing notes.
- `manifests/` — Source manifests, provenance records, checksums, and metadata.

## Important

These folders are currently empty placeholders. No NASA datasets are included in this archive. Add only data you have actually obtained and are permitted to redistribute. Record the original NASA source URL, title, access date, and any applicable usage terms for each dataset.
